# typemotion-art-svg

A small local SVG generator associated with [TypeMotion.Art](https://typemotion.art/). It does not call the product website or export service.

Install: `npx jsr add @yananlee/typemotion-art-svg`. Import `renderText` from `@yananlee/typemotion-art-svg` and render SVG using your own text.
